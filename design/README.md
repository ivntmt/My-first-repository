# Дизайн лендинга

Тёмный технологичный лендинг для IT-продукта (SaaS), цель страницы: оформить подписку. Одна страница, три ширины: 1440, 768, 375.

| Файл | Содержимое |
|---|---|
| `DESIGN-SYSTEM.md` | Цвета, типографика, сетка, отступы, радиусы, эффекты, все компоненты и их состояния |
| `LANDING-SPEC.md` | Блоки страницы с размерами, текстами и поведением на трёх ширинах |
| `FIGMA-GUIDE.md` | Как собрать это в Figma пошагово |
| `tokens.json` | Токены в формате Tokens Studio, импортируются в Figma Variables |
| `prototype.html` | Кликабельный прототип. Вкладка «Лендинг» и вкладка «Дизайн-система» (токены и компоненты отдельно) |

Откройте `prototype.html` в браузере. Тексты, название «Продукт», тарифы и цифры в макете являются примерами.
