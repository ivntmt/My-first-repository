# Как собрать дизайн в Figma

Файл `.fig` я создать не могу: у меня нет доступа к Figma. Но все данные подготовлены так, чтобы собрать файл за один вечер без догадок: токены импортируются, а размеры и состояния записаны в `DESIGN-SYSTEM.md` и `LANDING-SPEC.md`.

## 1. Подготовка (10 минут)

1. Создай в Figma файл «Лендинг · Продукт».
2. Установи плагин **Tokens Studio for Figma** (бесплатный план достаточен).
3. Установи шрифты **Onest** и **JetBrains Mono**. В Figma они доступны из библиотеки Google Fonts, локальная установка не нужна.

## 2. Импорт токенов (5 минут)

1. Открой плагин, раздел **Settings → Sync → Add new → Local file** или вставь содержимое `tokens.json` в **Tokens → Edit as JSON** (набор `global`).
2. Нажми **Apply**: токены `color`, `font`, `typography`, `space`, `radius`, `size`, `shadow` появятся в списке.
3. Создай стили и переменные: **Styles & Variables → Export** и выбери:
   - Color variables и Color styles
   - Text styles (из набора `typography`)
   - Effect styles (из `shadow`)
   - Number variables (`space`, `radius`, `size`)
   Названия пунктов меню плагина могут отличаться в разных версиях. Суть та же: импортировать JSON и экспортировать токены в стили и переменные.
4. Проверь имена: в Figma должны быть `bg/base`, `surface/1`, `text/primary`, `accent/600` и так далее.

Если плагин не подходит, создай переменные вручную по таблицам в `DESIGN-SYSTEM.md`: одна коллекция `Colors`, одна `Numbers`. Текстовые стили занесены в таблицу §2.

## 3. Структура файла

Страницы Figma (слева направо):

| Страница | Что внутри |
|---|---|
| `Cover` | Название, версия, дата |
| `Foundations` | Цвета, типографика, сетка, отступы, радиусы, эффекты, иконки |
| `Components` | Component Set каждого компонента с всеми вариантами |
| `Landing` | Три фрейма: Desktop 1440, Tablet 768, Mobile 375 |
| `Prototype` | Связи для проверки: прокрутка, меню, переключатель периода |

## 4. Порядок сборки

1. **Foundations.** Выложи образцы цветов (квадрат 96×64 + название токена), таблицу текстовых стилей, сетку. Образцы можно взять из вкладки «Дизайн-система» в `prototype.html`.
2. **Иконки.** Нарисуй 8 иконок на сетке 24×24 с обводкой 1,5 и скруглёнными концами. Контуры (`path`) лежат в `prototype.html`, массив `ic` в конце файла: скопируй путь, в Figma вставь как SVG.
3. **Компоненты** в таком порядке: Button → Badge → Segmented control → Header → Feature card → Step → Pricing card → CTA card → Product window → Footer. Для каждого: auto layout, свойства (Variant, Size, State) и токены вместо ручных значений. Параметры в `DESIGN-SYSTEM.md` §9.
4. **Landing / Desktop.** Фрейм 1440, вертикальный auto layout без зазора, внутри блоки в порядке из `LANDING-SPEC.md`. Включи Layout Grid: 12 колонок, gutter 24, тип Center, ширина 1200.
5. **Tablet и Mobile.** Продублируй фрейм и поменяй ширину. Включи сетки 8 и 4 колонки. Перестрой блоки по правилам «Планшет / Мобильный» из спецификации. Используй те же компоненты.
6. **Прототип.** Свяжи кнопки и ссылки с блоками (см. раздел «Состояния и поведение»).

## 5. Правила, чтобы дизайн остался аккуратным

- Никаких цветов, размеров и шрифтов «из головы»: только токены и стили.
- Компоненты не разрываются (Detach). Отличия оформляются свойствами.
- Все отступы кратны 4.
- Основная кнопка на экране одна. Для белого текста на фиолетовом фоне только `accent/600`.
- Перед передачей разработчику проверь контраст плагином (Stark, Contrast) на всех состояниях.

## 6. Передача в разработку

`tokens.json` в формате Tokens Studio. Для Style Dictionary его нужно предварительно конвертировать (например, пакетом `token-transformer`). `prototype.html` содержит готовую вёрстку с теми же значениями (CSS-переменные в `:root` соответствуют токенам). Её можно взять как основу.

## Если подключён Figma-коннектор

Если у тебя в Claude подключён Figma-коннектор, я могу попробовать работать напрямую: проверить доступ, создать или обновить файл. В этой сессии такой возможности нет.
